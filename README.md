# 学习通自动学习助手

基于脚本猫（ScriptCat）/ 油猴（Tampermonkey）的学习通 / 超星课程自动学习脚本。

**当前版本：v4.0.1**

> v4.0.0 是**可靠性版本**：不再靠人盯，而是让脚本自我约束。
> ① **抖动自检熔断**——60 秒内播放/暂停切换超过阈值就自动停手（3.2.2 修的是具体成因，这版加的是兜底网）；
> ② **音频任务点**——真正需要播放的音频不再只靠滚动；
> ③ **本页任务点诊断**——面板直接显示识别到几类任务点、多少题，下次在真实测验页一眼定位问题。
>
> 3.x 线：v3.2.2 修播放/暂停拉锯；v3.2.1 空小节跳过；v3.2.0 断点续刷 + 课程链；v3.1.0 非视频任务点与人脸核验；v3.0.0 支持新泛雅 / mooc2-ans。

> v3.2.2 修掉真实刷课暴露的播放/暂停拉锯（已触发过风控）：播放尝试限频 + 顶层在子实例有心跳时让位。
>
> v3.2.0 解决"刷课的连续性"：刷新 / 重进后自动跳回上次小节（断点续刷），
> 一门课刷完可接着进下一门没进过的课（课程链，默认关闭）。
>
> 之前两版：v3.1.0 补非视频任务点与人脸核验保护；v3.0.0 支持新泛雅 / `mooc2-ans`。
> 更早的结构性重构见 [调研报告](学习通自动化调研报告.md)。

## 断远控 / 后台稳定运行（v4.0）

脚本依赖页面定时器与媒体解码。**断开远程桌面后**，Windows 会把浏览器窗口判为「被遮挡」，
Chromium 随即节流定时器并暂停媒体渲染 —— 表现为黑屏、面板显示「已暂停」、进度不再增长。
用带反节流参数的 Edge 启动可以缓解（本项目实测有效）：

```powershell
pwsh -NoProfile -File .\tools\start-edge.ps1 -Url 'https://i.chaoxing.com/base'
```

| 参数 | 作用 |
|---|---|
| `--disable-background-timer-throttling` | 后台不节流 setTimeout / setInterval |
| `--disable-renderer-backgrounding` | 不被降级为后台渲染进程 |
| `--disable-backgrounding-occluded-windows` | 被遮挡的窗口不当后台处理 |
| `--disable-features=CalculateNativeWinOcclusion` | 关掉 Windows 遮挡计算 |

⚠️ 两个前提：① **必须先把所有 `msedge.exe` 关掉**再运行本脚本 —— Edge 是单实例程序，
已经在跑时新命令通常只是把 URL 转交给现有进程，**参数完全不生效**；② 这些参数只对本次启动生效。
启动器检测到已有进程时只警告、不会替你杀进程。

**边界**：这只解决「浏览器节流」。若平台播放器自己就是「页面无焦点即暂停」，
仍然要靠脚本侧的播放节流与抖动熔断兜底——两者不是替代关系。

## 路线图：v4.0 之后（据 research/beyond-v4.md 的实测结论排序）

1. **同页多任务点（tab 切换）** —— 一页可能挂两个任务点（视频 + 章节测验、音频 + 听力练习），
   平台用 `#prev_tab a[cardid]` → `changeDisplayContent(cardid)` → 改 `#cardId`。
   我们目前只有「下一节整页跳转」，同页第二个任务点只能靠运气。
   **选择器未在真实页面验证，故 4.0 未实现**（宁可不做，也不要在你的账号上盲试）。
2. **音频播完回读标记** —— 实测音频播到 97.6% 正常结束，标记仍是「未完成」；需要回读 `aria-label` 再决定是否算完成，
   现在的实现只负责播放，不回读。
3. **`work` 两态判定** —— `doHomeWorkNew`（待作答）vs `selectWorkQuestionYiPiYue`（已批阅），
   判据用「有没有 `a.btnSubmit`」比标题/URL 可靠，可把大量 `unknown`（→不交）降下来。
4. **熔断误判源** —— 开播 90 秒内向前大跳属平台续播；`readyState < 3` 时不应判「卡住」。

**明确不做**（已被验证失效或风险过高）：绕人脸、秒刷 / 直接打 `complete`、伪造接口或心跳、
多端并发、拖拽补时长、考试自动交卷。证据见 `research/beyond-v4.md`。

## 新版平台支持（mooc2-ans / 泛雅）

2026 年起多数学校的学习通换成了「新泛雅」：个人空间外壳是 `fycourse.fanya.chaoxing.com`，
课程目录是 `mooc2-ans.chaoxing.com`，点小节走 `toOld(courseId, chapterId, clazzId)` 跳回**经典** `mooc1` 学习页，
而播放器又被放进 `mooc1.chaoxing.com/ananas/modules/video/index.html` 这个 iframe。

老版本在这条链路上有四处对不上，表现是：面板一切正常，但「视频：未检测到」、进度永远 0%、一节放完也不切节。

| 断点 | 旧实现 | v3.0.0 |
|---|---|---|
| 视频在哪 | 只查本地文档 `doc.querySelectorAll('video')` | 顶层跨所有**同源** iframe 收集；子框架仍只看自己，避免父子两套实例抢同一个 video |
| 可见性判定 | `win.getComputedStyle()` 判子文档元素，拿到的是错值甚至抛错 | 改用元素自己的 `ownerDocument.defaultView` |
| 目录当前项 | 只认 `.currents` / `.active` / `.posCatalog_active` | 增加新版 `#cur{chapterId}`（`[id^="cur"]`），否则 `goNext()` 判「未找到下一任务点」，不再切节 |
| 完成标记 | `.icon_Completed` / `.ans-job-finished` | 增加 `.ans-job-icon`：**classes 里没有 `-clear` 即视为已完成**，不必猜新版的完成态类名 |

**怎么确认生效**：面板显示「视频：已接管」即接管成功；仍是「未检测到」说明播放器在**跨域** iframe 里，
需要在头部 `@match` 补该域名（例如 `// @match *://*.example.edu.cn/*`）。

> ⚠️ 平台有风控。实测短时间内大量跳转 / 刷新会触发 `antispiderShowVerify.ac` 的
> 【9010】操作异常验证码，且官方判定是**延迟批量清算**——「今天刷完没事」不等于安全。
> 请控制操作频率，不要连续刷新同一个学习页。

## 安装

1. 安装脚本猫（ScriptCat）或油猴（Tampermonkey）
2. 新建脚本，粘贴 `xuexitong-assistant.user.js` 全部内容并保存
3. 打开学习通课程视频页，右下角出现面板即生效

学校自有域名，在脚本头部 `@match` 补充一行：

```
// @match        *://*.example.edu.cn/*
```

## 面板操作

面板会挡到页面内容时**折叠**它——只留一行状态摘要：

| 操作 | 效果 |
|---|---|
| **点标题栏** | 折叠 / 展开（最常用） |
| `Alt+W` | 同上，键盘等价操作 |
| `Alt+Q` | 隐藏 / 显示整个面板（和折叠不同：隐藏后完全不见） |

折叠后标题变成一行摘要，仍能看关键状态：

```
学习通助手 ▸ 运行中 · 45% · 弹题3
              ↑状态  ↑进度  ↑已答弹题数
```

**折叠状态会记住**（存 GM storage），下次打开页面保持上次选择。如果面板完全挡住了内容又不想关脚本，折叠是最优解。

## 快速开始：默认行为是什么

装上之后**默认就是这个状态**，不需要配置：

| 项 | 默认 | 含义 |
|---|---|---|
| 视频 | 自动播放、静音、1x | 倍速可手动切到 1.25/1.5/1.75/2 |
| 跳转 | 播完 + 平台记录出现才跳 | 不会 90% 就跳 |
| 作息 | **只在 7:00–23:00** | 夜间自动暂停并说明原因 |
| 拟人化 | 开（随机暂停 + 时段） | 可单独关随机暂停 |
| 章节测验 | 自动作答 + 自动提交 | 测验可重做，风险低 |
| 作业 | 自动作答，**不自动提交** | 作业通常只有一次机会 |
| 考试 | 自动作答，**永不提交** | 硬编码禁止，改配置也无效 |
| 每日上限 | 只识别平台提示，不设本地数字 | 阈值无据可查 |
| AI 答题 | **需要你填 Key** | 不填则只用本地题库 |

**至少要做一件事**：点面板「设置Key」填一个 AI Key，否则答题只能靠本地题库和随机兜底。

## 配置表

所有配置在脚本顶部 `DEFAULTS`。**依据等级**：`A` = 有平台规则/源码实证；`B` = 一手实测；`C` = 社区经验；`—` = 无依据（保守默认）。

### 播放与完播

| 配置 | 默认 | 依据 | 说明 |
|---|---|---|---|
| `speed` / `maxSpeed` | 1 / 2 | A | 平台官方支持 ≤2x；>2x 会清空已完成任务点 |
| `requireEnded` | true | A | 必须等 `ended` 才跳（`isdrag=4` 是任务点判定信号） |
| `nextAtPercent` | 98 | A | `requireEnded=false` 时的备用阈值 |
| `completeDelay` | 5000 | B | 播完后等多久再跳，留给平台上报 |
| `endedFallbackMs` | 20000 | — | 到 99.5% 仍无 `ended` 时兜底跳 |
| `minWatchSeconds` | 30 | — | 至少播放秒数（短视频按 90% 封顶） |

### 每日上限（v2.3 新增）

| 配置 | 默认 | 依据 | 说明 |
|---|---|---|---|
| `detectPlatformDailyLimit` | true | A | 识别 `.maskDiv.jobCountDiv` + 逐字文案 + 可见，三条件 |
| `dailyTaskLimit` | **0（关闭）** | — | 本地软限。**阈值无据可查**，强推数字只会误伤 |
| `waitForCompletion` | true | A | 播完先等 `.icon_Completed` 再跳（`video.ended ≠ 任务点已记录`） |
| `completionTimeoutMs` | 30000 | — | 等标记的超时 |
| `completionMaxRetry` | 1 | — | 超时重播次数；额度用完即硬跳（防无限重播） |
| `examMaxPages` | 50 | — | 分页考试的页数上限（防死循环） |

### 答题策略（v2.3 新增）

| 配置 | 默认 | 说明 |
|---|---|---|
| `answerObjective` | true | 单选/多选/判断：本来就能可靠落点 |
| `answerFill` | true | 填空；多空用 `\|` 分隔，段数对不上就放弃该题 |
| `answerSubjective` | **false** | 简答/名词解释/论述：AI 长文本风险高，平台常需人工批阅 |
| `answerCalc` | **false** | 计算题：过程分靠运气 |
| `fallbackRandom` | true | 无答案时随机选，**不固定选第一个**（"全选 A"是明显特征） |

### AI 答题质量（v2.3.1 新增）

| 配置 | 默认 | 说明 |
|---|---|---|
| `aiMaxTokens` | **256** | 原 64 太紧，模型想思考会被截断 |
| `aiRetryOnParseFail` | **true** | 解析不出答案时重问一次，别直接走随机兜底 |
| `aiVoteSamples` | 0（关闭） | 多采样投票：同一题问 N 次取多数。**0=只问一次；建议 3**（成本 3x，准确率明显提升） |
| `aiModel` | `deepseek-flash` | **换更强的模型是提升准确率最有效的手段**（如 `deepseek-v4-pro`） |

### 拟人化（v2.3 新增）

| 配置 | 默认 | 依据 | 说明 |
|---|---|---|---|
| `humanize` | true | — | 总开关：关掉后下面两项整体失效 |
| `humanizePause` | true | — | 随机暂停，可单独关（保留时段保护） |
| `humanizePauseChance` | 0.0005 | — | 每 tick 触发概率，≈33 分钟一次 |
| `humanizePauseMin/Max` | 3/15 | — | 暂停时长（秒） |
| `humanizePauseBudget` | **0.05** | B | 暂停总时长/已播时长 ≤5%。**超过会降低有效观看率**，撞 ≥90% 口径 |
| `humanizeMinGapSec` | 180 | — | 两次暂停最小间隔 |
| `humanizeResumeCheckMs` | 2500 | — | 恢复后校验进度是否推进，不推进点播放按钮 |

### 非视频任务点与人脸核验（v3.1 新增）

| 配置 | 默认 | 说明 |
|---|---|---|
| `docTask` | true | 是否自动推进**文档 / PPT / 音频**任务点（视频与题目另有开关） |
| `docScrollRatio` | 0.9 | 每次滚动多少屏。调大更快，但"瞬间读完"是典型机器特征 |
| `docScrollIntervalMs` | 1200 | 两次滚动间隔（毫秒）；`0` 表示不节流，**仅供测试** |
| `pauseOnFace` | true | 检测到人脸核验遮罩时暂停自动推进并提示 |
| udioTask | true | 是否自动播放音频任务点（限频沿用 controlGapMs） |
| lapMaxPerMin | 12 | 抖动熔断阈值：60 秒内 play/pause 切换次数上限 |

**工作原理**：新版任务点容器是 `.ans-attach-ct:has(.ans-job-icon)`，视频任务点额外带 `ans-job-video`；
其余类型只有滚动阅读或播放才会被平台记录。脚本对未完成的非视频任务点按 `docScrollRatio` 逐步下滚，
完成判据仍是「`.ans-job-icon` 去掉 `-clear`」。滚到底仍未完成时，只尝试常见的「下一页」按钮，找不到就停下并报状态——不硬刷。

**音频任务点的边界**：完成态过滤依赖「音频位于 `.ans-attach-ct` 任务点容器内」。若平台改版把播放器提到容器外，`closest()` 返回 null，过滤会被跳过——「已完成但被暂停」的音频仍可能被拉起。这是已知边界，暂不处理。

**人脸核验**：只做探测（`#fcqrimg` / `.chapterVideoFaceMaskDiv` / class 或 id 含 `face` 且文案匹配）。
命中即暂停视频、停掉所有自动推进、在面板写明原因；人工完成后自动恢复。**不模拟、不绕过。**

### 断点续刷与课程链（v3.2 新增）

| 配置 | 默认 | 说明 |
|---|---|---|
| `resume` | true | 刷新 / 重进后自动跳回上次所在小节 |
| `resumeMaxAgeHours` | 12 | 断点有效期（小时）；超过就不跳，避免几天后突然跳回旧节 |
| `courseChain` | **false** | 一门课刷完自动进下一门没进过的课。**默认关闭**，需显式开启 |
| `courseChainMaxAgeMin` | 5 | 从「本课结束」到「进下一门」的有效窗口（分钟） |

**为什么用 chapterId 而不是小节标题**：标题会随老师改文案变化，平台也会改版式；`chapterId` 是稳定主键。
脚本从三种已知形态解析它：URL 的 `chapterId=`、目录节点的 `onclick="toOld('courseId','chapterId',…)"`、以及当前节点的 `id="cur{chapterId}"`。
解析不出来时**返回空而不错猜**——猜错会跳到别的小节，白刷一节还不报错。

**为什么课程链默认关**：跨课程自动操作的影响面比单课内跳转大得多（可能进入你并不想刷的课）。
按本项目一贯的保守默认（1x 倍速、安全模式开、考试永不自动交），这类能力需要显式开启：
把 `DEFAULTS.courseChain` 改成 `true`。

**防抖**：断点续刷每次页面加载**只尝试一次**，找不到就放弃；课程链有 5 分钟窗口且只尝试一次。
反复跳转正是最容易触发平台风控的行为，这里刻意不做重试。

## 字体解码怎么工作

学习通把题目文本用自定义 TTF 渲染：DOM 里的 `textContent` 是字符 A，人眼看到的字形却是字符 B。**直接把 textContent 送去 AI，等于在乱码上答题。**

流程：

1. 从 `@font-face` 找到 `font-cxsecret` 的字体 URL，下载 TTF
2. 解析 `cmap` 表拿到字体覆盖的码位（支持 format 4/12/6）
3. 用 `FontFace` 加载，Canvas 渲染每个码位 → 100 维特征向量
4. 用 4 种基准字体渲染 3000 常用字 → 特征池（分批渲染不卡 UI）
5. 余弦相似度匹配，超过 `fontConfidence` 才采用
6. 映射按**字体内容哈希隔离**（不同试卷同码位真字不同，绝不共用）

**关键安全设计**：解码失败时**不静默输出错字**——面板显示原因，且默认拒绝答题。

## 已知限制

1. **题型标签必须是标准写法**
   `「第1题 单选题」「单选题 2分」`这类带装饰的写法不认（退回数字码/结构判断，通常仍能正确作答）。
   支持：`单选题` / `【单选题】` / `1.（单选题）` / `判断题（2分）` / `（名词解释题）`

2. **`waitForCompletion` 依赖单一选择器族**
   只认 `.icon_Completed` / `.ans-job-finished`。若平台改版换选择器，会白等 30 秒后硬跳（有兜底，但会慢）。
   缓解：只在页面**确实存在**标记族时才等。

3. **重播依赖视频能再次 `ended`**
   若视频卡在半路不再触发 `ended`，重播不会发生（无 watchdog）。此时停在"重播中"状态。

4. **作答异常后需刷新页面**
   `workLock` 会恢复，但 `workSolved` 已置位 → 同一页不会自动重试。面板会提示「请刷新页面重试」。

5. **分页考试判定是单信号**
   只看 `.mark_info` 含「不允许整卷预览」。缺失则退回两遍法（只答第一页；考试不提交，安全）。

6. **本地日限默认关闭**
   没有 `spreadDays` 自动估算——脚本只能控制单次运行，无法强制跨天。
   分天建议：一门 40 节的课，**分 10 天各 4 节**（约 54 分钟/天）。依据是公文「学习周期至少一周以上」。

7. **客户端指纹未完全消除**
   面板标题、存储 key（`cxas_*`）、`document.__cxasTaken` 仍是固定字符串。已随机化的是面板 id/class/cssText 与字体探测的 family 名。

8. **答题准确率有上限**
   中文四选一基准上 LLM 的天花板是 60–70%（C-Eval），便宜模型更低。见下节「提升答题准确率」。

## 提升答题准确率

先说清楚：**AI 答题不可能 100%**。学界在中文四选一上的实测是 **60–70%**（C-Eval），真实考试题 54–71%，`deepseek-flash` 这类便宜模型落在这条线的下沿。

脚本能做的是把"本可以答对"的题答对，剩下的靠你选：

### 已内置的改进（v2.3.1）

| 改进 | 作用 |
|---|---|
| **题型标注进 prompt** | 明确告诉模型「【多选题，可能有多个正确答案，请给全部】」——不标注时模型常只给一个字母 |
| `aiMaxTokens: 256`（原 64） | 给模型留思考空间，避免被截断 |
| `aiRetryOnParseFail: true` | 解析不出答案时重问一次，而不是直接走随机兜底 |
| **面板显示「上次得分」** | 提交测验后从页面读真实分数，准确率不再靠感觉 |
| `fallbackRandom: true` | 兜底随机选，去掉"全选 A"这个明显特征 |

### 你可以调的（按性价比排序）

| 手段 | 成本 | 效果 | 怎么开 |
|---|---|---|---|
| **换更强的模型** | 中 | **最大** | 面板点模型按钮，换 `deepseek-v4-pro` / `kimi-k3` / `glm-5.3` |
| **开多采样投票** | 3x token | 中-高 | 代码里改 `aiVoteSamples: 3` |
| 导入题库 | 一次性 | 高（有原题时） | 面板「导入题库」，`.json`/`.txt`/`.csv` |
| 提高 `fontConfidence` | 0 | 中（如果解码有错字） | 改 `fontConfidence: 0.8`，宁可放弃也不答错 |

**优先级建议**：先看面板「上次得分」——如果 60 分以下，**先换模型**（收益最大）；如果模型已经不错但还是低，再开 `aiVoteSamples: 3` 或多导入题库。

### 关于「命中率」和「上次得分」的区别

面板上这两行意思完全不同：

- **命中率** = 有答案的题占比（题库/AI/远程命中），**不代表答对**
- **上次得分** = 提交测验后从页面上读到的真实分数，**这才是准确率**

只看命中率会被误导——答得又快又全，可能错一半。

## 合规声明

**不做的事**（代码里没有，也不接受 PR）：

- ❌ 绕过验证码 / 滑块 / 人脸
- ❌ 伪造签到活动
- ❌ 多端并发（本脚本的 `singleSession` 是**防止**多端，不是支持）
- ❌ 自动提交作业/考试（考试提交硬编码禁止）

**法律边界**：现有判例把"制作、提供、售卖"此类辅助程序认定为提供侵入、非法控制计算机信息系统程序、工具罪。**个人自用与分发售卖性质不同**——请勿分发、售卖或代刷他人账号。

平台已声明用 AI/大数据监控刷课行为并可能通报高校，且判定是**延迟批量清算**——"今天刷完没事"不等于安全。

| 能力 | 说明 |
|---|---|
| 抖动自检熔断 | 监听 video 的 play/pause 事件；60 秒窗口内超过 `flapMaxPerMin`（默认 12）次切换 → 自动暂停脚本并持久化，面板写明「已熔断」 |

**设计取舍：熔断后不自动恢复。** 自动恢复会让「抖动 → 熔断 → 恢复 → 再抖动」变成循环，
而这正是最像机器人的行为。宁可停下来等人看一眼。

**为什么要有兜底网**：3.2.2 修的是「每秒抢控制权」这个具体成因，但任何后续改动都可能重新引入抖动，
而抖动一旦发生就是在拿账号风险换进度。与其每次都靠人盯面板，不如让脚本自己发现自己在抽风。

### 3.2.2

**修复：播放 / 暂停拉锯（真实刷课暴露，已触发风控）**

| 根因 | 说明 | 修法 |
|---|---|---|
| 每秒抢控制权 | `tickVideo()` 每 tick 都 `play()` + `clickPlayButton()`；平台一暂停就变成每秒拉锯 | 间隔 ≥ `controlGapMs`（默认 4s）才重试；合成点击只在前 2 次；连续 3 次失败即放弃并写面板 |
| 父子实例抢同一 video | 顶层跨 iframe 找到的 video，iframe 内实例也在驱动，拟人化暂停不同步 | 用子实例 STATS 作心跳，心跳有效（4s）时顶层让位 |
| 拟人化无限拉锯 | 暂停期间平台把视频拉起来，旧代码一直按回去 | 最多按 3 次，之后放弃本次拟人化暂停 |

### 3.2.1

**修复：空小节卡死**

有些目录节点打开后 cards 里是「暂无内容」（老师未发布 / 未开放），既没有视频也没有题目——

|---|---|
| 断点续刷 | 用 `chapterId`（URL / `toOld()` / `#cur{id}` 三来源）记住上次小节，刷新后跳回；12 小时过期；每次加载只尝试一次 |
| 课程链 | 本课到最后一节时回课程列表，挑一门**没进过**（按 `courseId` 记录）的课进入；默认关闭，5 分钟窗口，只尝试一次 |
| 面板 | 「最近动作」会写明「断点续刷：跳回上次所在小节」/「课程链：进入下一门课程」 |
| 测试 | 新增 `tests/resume-chain.test.js`（13 项断言）：三种 chapterId 来源解析、该跳/不该跳、过期不跳、目录缺失不崩 |

**刻意不做的事**：断点续刷不做重试。反复跳转是最容易触发风控的行为，找不到就放弃、把状态写在面板上。
