# 故障排查

按「现象 → 原因 → 怎么办」查。多数问题看一眼面板就能定位：
面板上的 `视频 / 进度 / 音频 / 人脸核验 / 抖动自检 / 本页任务点 / 最近动作` 就是现场快照。

---

## 面板显示「视频：未检测到」

| 可能原因 | 怎么确认 | 怎么办 |
|---|---|---|
| 脚本处于暂停态 | 面板「状态：已暂停」，按钮显示「启动」 | 点「启动」。暂停时 `tickVideo` 第一行就 return，不会再去找视频 |
| 播放器在**跨域** iframe 里 | 面板「最近动作」里有 iframe 列表日志（开 `verbose` 可见） | 在脚本头部补 `@match` 该域名 |
| 页面还在加载 | 等 5~10 秒 | 一般会自己恢复 |
| 脚本没注入这个框架 | 换个页面（如课程目录）看面板是否出现 | 检查脚本管理器是否允许「在 iframe 中运行」 |

> 判据：`视频：已接管` = 拿到了 video 元素；`未检测到` = 一个 `<video>` 都没找到。

## 面板显示「状态：已暂停」，但我没点过暂停

两种可能：

1. **抖动熔断**（v4.0 起）：面板「抖动自检」会写 `已熔断（60 秒 N 次切换）`，
   「最近动作」写明原因。这是**保护**，不是故障——说明有东西在反复 play/pause。
2. 以前点过暂停，状态被持久化了。

**不会自动恢复**是刻意的：自动恢复会让"抖动→熔断→恢复→再抖动"变成循环。

## 只有一个学习页，面板却提示「检测到另一标签页正在学习」

面板「状态：运行中」，但「最近动作」是「检测到另一标签页正在学习，已主动暂停」，
视频 `paused=true` —— 明明只开了一个学习页，却像在跟谁抢。

**这是 v4.0.1 及更早版本的 bug，v4.0.2 已修。** 单端纪律用 localStorage 心跳判断"有没有别的标签在学"，
但心跳原本是**每个 frame 都写**的：一个学习页里有 3 个 frame（顶层 / `knowledge/cards` / `ananas` 播放器），
等于出现 3 个"活标签"。仲裁规则是"ID 字典序最小的赢"，播放器 frame 的 ID 有约 1/3 概率更小，
顶层就会主动让路把视频暂停 —— 暂停后子 frame 心跳转 `playing:false`，双方又开始互相礼让，最后谁都不播。
因为 tab id 是随机的，这个自锁**时有时无**，极难复现（同一套脚本可能昨天跑一整天没事、今天一开就锁死）。

**处理**：升级到 v4.0.2 后刷新学习页。v4.0.2 只让顶层 frame 参与互斥，并会在启动时清理过期心跳。

诊断方法（在学习页控制台执行）：

```js
Object.keys(localStorage).filter(k => k.startsWith('cxas_hb_')).length
```

正常应 ≤ 2（自己一个 + 偶发残留）；v4.0.1 下见过 3 个以上，一次会话最多积到 86 个死键。

## 视频播完了但不跳下一节

| 原因 | 面板线索 | 怎么办 |
|---|---|---|
| 等平台完成标记 | 「进度：100%」但「最近动作」还在等 | 等 30 秒；脚本超时后会硬跳一次 |
| 目录当前项识别不到 | 「最近动作：未找到下一任务点」 | 该平台的当前项 class 不在 `CATALOG_ACTIVE_SELS` 里，需要补选择器（新版是 `#cur{chapterId}`） |
| 本节有多个任务点 | 「本页任务点」显示 `video×1 doc×1` | 同页第二个任务点目前**未实现自动切换**（见 README 路线图第 1 项） |
| 平台提示日上限 | 「平台日上限：已触发」 | 今天到此为止，明天再刷 |

## 音频任务点不播放

- 浏览器**自动播放策略**会拦下没有用户交互的 `play()`：先手动点一下页面任意位置。
- 面板「音频」显示 `未播放 0s` 且一直不动：可能是非 `<audio>` 的自定义播放器，脚本无法通用驱动（已知边界）。
- 显示 `暂停中`：音频落在已完成的任务点里，脚本按设计不再拉起它。

## 断开远程桌面后黑屏 / 进度不走

这是**浏览器节流**，不是脚本问题：Windows 把窗口判为「被遮挡」，Chromium 节流定时器并暂停媒体渲染。

注意：**学习页被切到后台标签**也会被节流（即使没断远控）——页面看着正常，但进度不动、脚本像失联、
从外部探测还会超时。要么把学习页留在前台，要么用下面这条命令起一个带反节流参数的 Edge。

```powershell
# 先把所有 msedge.exe 关掉（单实例程序：已有进程在跑时新命令只转交 URL，参数不生效）
pwsh -NoProfile -File .\tools\start-edge.ps1 -Url 'https://i.chaoxing.com/base'
```

细节见 `tools/README.md`。

## 跳到某一节就停住不动

打开的那一节是「暂无内容」（老师未发布 / 未开放）。v3.2.1 起会自动跳过，但**10 分钟最多跳 5 次**；
超过就停手并提示「连续 N 个空小节，已停止自动跳转」——整章未发布时连环跳同样像机器人。

另有一种**播放器卡死**：视频停在开头几秒（例如 `0:02`），`play()`、点播放键都不动，但
`buffered` 正常、`readyState=4`、无 media error、任务点仍显示「未完成」。
2026-11-04 实测撞到过一次，多发生在**连续快速跳过若干空小节、紧接着进入视频**的时候。

**处理：刷新页面一次，再点「启动」。** 刷新能让播放器拿到全新状态（脚本的抖动计数也会随之归零）。
如果刷新后仍然不播，先看是不是已经触发风控，别反复刷新。

## 弹出【9010】操作异常 / 图片验证码

平台风控。**脚本不会也不能过验证码。**

1. 手动输一次验证码；
2. 之后**减少操作频率**：不要在短时间内反复刷新学习页、反复重装脚本、反复换节；
3. 风控判定是**延迟批量清算**的，"今天刷完没事"不等于安全。

## 面板突然消失

- 页面整页跳转（换节/交卷）后会重建，属正常；
- 被折叠了：点标题栏展开（折叠态标题会显示成一行状态摘要）；
- 脚本被脚本管理器禁用/更新中断：刷新页面。

## 字体解码失败 / 题目里是乱码

面板「字体解码：待触发」→ 说明还没遇到题目页（正常）；「字体解码：就绪」但题面仍乱码，
说明字体基准池没匹配上，可以：

1. 面板点「导出日志」，把日志发出来；
2. 临时关掉字体解码（`CFG.fontDecode = false`）避免在乱码上答题——**错答比不答更糟**。

## 想让人帮你定位问题

面板右下角有「**导出日志**」，导出后会得到一份包含最近动作、识别结果、配置的文本。
贴日志时**先去敏**（不要带 API Key、不要带账号 cookie）。
